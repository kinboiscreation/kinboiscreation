## 🎵 Background Music

### background-music-emotional-journey.mp3
**Duration**: 40 seconds (full video)  
**Volume**: 30% (0.3 in code) to not overpower dialogue  
**Format**: MP3 or WAV, 44.1kHz or 48kHz, stereo

**Emotional Arc** (follows Myrtille's journey):

```
0-3s (Entrance):
  - Tense, discordant
  - Minor key
  - Unstable rhythm
  - Volume: Low-medium

3-8s (Pacing):
  - Building tension
  - Increasing chaos
  - Fast tempo
  - Volume: Medium

8-17s (Conflict):
  - Peak tension
  - Dissonant harmonies
  - Heavy rhythm
  - Volume: Medium-High

17-22s (Peak anger):
  - Maximum tension
  - Chaotic
  - Loud and intense
  - Volume: High

22-28s (Turning point):
  - Gradual shift
  - Introduction of resolved themes
  - Slower tempo begins
  - Volume: Decreasing

28-34s (Calming):
  - Peaceful, resolved
  - Major key introduced
  - Harmonic resolution
  - Volume: Medium-Low

34-40s (Resolution):
  - Peaceful, uplifting
  - Major key
  - Harmonious
  - Warm, hopeful
  - Volume: Low-Medium
```

## 🔧 How to Create Audio Files

### Option 1: AI Text-to-Speech (Recommended for consistency)

**ElevenLabs** (High quality, French voice):
```bash
# Install Python SDK
pip install elevenlabs

# Generate speech
python generate_voice.py
```

**Google Cloud Text-to-Speech**:
```bash
gcloud text-to-speech --text="Non mais franchement..." \
  --language-code=fr-FR \
  --output-file=myrtille-anger-01.mp3
```

**Azure Speech Services**:
Similar REST API for French TTS

### Option 2: Record Yourself

Using Audacity (free):
1. Open Audacity
2. Record each dialogue
3. Use French pronunciation guide
4. Cut silence at start/end
5. Normalize audio levels
6. Export as MP3 (128-192 kbps)

Platforms:

- Upwork (French voice talent)

## 🔊 Audio Levels (Mixing)

### Target Levels

```
Dialogue:        -6dB to -12dB (primary)
Background Music: -18dB to -24dB (30% volume)
Ambient Sounds:   -24dB to -30dB (subtle)
Peak:             -3dB (avoid clipping)
```

### Mixing Tips

1. **Dialogue first**: Record/generate at good level
2. **Background music**: Lower to 30% volume
3. **Ambient**: Very subtle, almost subconscious
4. **Test**: Listen at normal volume, it should sound natural
5. **Mix down**: Export final mix at -3dB peak

## 🚨 Troubleshooting

**Audio not playing?**
- Check file format (MP3 or WAV)
- Verify file paths in `AudioLayerCinematic.tsx`
- Check `public/audio/` directory exists
- Refresh Remotion Studio

**Dialogue out of sync?**
- Check frame numbers match timing
- Remember: 1 frame = 1/30 second = 33ms
- Adjust `from` and `durationInFrames` values

**Volume issues?**
- Adjust 0.3 to 0.5 for louder music
- Adjust 0.9 to 0.7 for quieter dialogue
- Aim for balanced mix (dialogue > everything)

**Noise in audio?**
- Use noise reduction in Audacity
- Record in quiet room
- Use pop filter for recording
